## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_advertising_package_booking`** is the official reservation and financial checkout module for **UNIVERSE HUOKAING THARA Group**. It empowers brands, advertising agencies, and corporate sponsors to configure campaign durations, select targeted sponsorship tiers, bundle production add-ons, and instantly generate official booking vouchers with transparent pricing and multi-month discount incentives.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🧮 Live Order Summary Calculator:** Real-time calculation engine that instantly updates base rates, multi-month commitment discounts (up to 20% off), production add-on costs, estimated cumulative reach, and final totals.
* **⚡ Step-by-Step Reservation Flow:** Streamlined 3-step configuration interface (*Tier Selection → Duration & Add-ons → Client & Payment Method*).
* **🧾 Automated Booking Voucher Modal:** Generates a secure tracking reference code (`UHT-BK-XXXXXX`) and a comprehensive reservation summary receipt upon successful submission.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 📋 Interactive Booking Flow / ដំណើរការកក់សេវាកម្ម

1. **Tier Selection:** Choose from Starter Digital (`$250/mo`), Standard Media (`$600/mo`), VIP Sponsor (`$1,500/mo`), or Global Executive Partner (`$3,500/mo`).
2. **Duration & Commitments:** Select campaign duration (`1, 3, 6, or 12 Months`) with automatic discount scaling (`0% to 20% savings`).
3. **Production Add-Ons:** Bundle custom commercial video shoots or exclusive narrator shoutouts by Mr. Chorn Rothanak.
4. **Checkout & Voucher:** Enter brand details, choose preferred payment channels (`Bank 1`, `Bank 2`, `KHQR`, or `Corporate Wire`), and generate the official confirmation voucher.

## 🛠️ Tech Stack & Architecture / បច្ចេਕវិទ្យាប្រើប្រាស់

- **Frontend Core:** Semantic HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro` for Khmer script, `Poppins` for English UI)
- **Icons:** FontAwesome v6.4.0
- **UI/UX Design:** Cyberpunk Holographic Dark/Light Theme with Scanline Overlay
